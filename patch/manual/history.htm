更新历史

　

  • Ver1.09 -> Ver1.10 变更内容
  • 修正了全屏瞄准框不显示的 Bug。
  • 分数数据的保存位置改为安装目录文件夹。
　
  • Ver1.08 -> Ver1.09 变更内容
  • 启动时的默认设置改为：无跳帧、640x480 分辨率、PCM 音乐播放。
  • 各关卡标题、OP、ED 等的文字字体改为高分辨率版本。
  • 从设置程序启动的手册改为 HTML 格式。删除了半透明改网点的模式。
  • 改用基于 ver1.09 的安装程序。

　

  • Ver1.06 -> Ver1.08 变更内容
  • 支持 Ogg Vorbis 的 BGM 播放。
  • 特殊绘制中追加了纵向线卷动。
  • 因支持 PCM 的 BGM 播放，所需运行配置提高。
　
  • Ver1.04 -> Ver1.06 变更内容
  • 修正了第 2 关中一部分角色不消失的 Bug。
  • 追加了竖置画面模式。
  • 追加了各种特效。
  • 追加了特殊绘制特效。
  • 从关卡选择开始游玩时，中断后将返回关卡选择画面。
  • 启动菜单升级为 ver1.06 对应版，并改为保存设置信息。
  • 追加了针对屏幕保护程序及省电模式的对策处理。

　

  • Ver1.03 -> Ver1.04 变更内容
  • 修正了可能导致非法退出的 Bug

　

  • Ver1.02 -> Ver1.03 变更内容
  • 修正了启动后立即非法退出的可能问题
  • 修正了游戏中可能非法退出的问题（应该是修好了——）
  • 追加了一部分敌机　
  • 修正了雷刀消除激光的动画不显示的问题
  • 变更了存档文件的格式
  • 实装了可使用量产机的模式
  • 照例还改动了许多细小的地方

　

  • Ver1.01 -> Ver1.02 变更内容
  • 追加了启动用程序并更改了画面模式的选择方式　
  • 支持 640x480 分辨率
  • 3DCG 类图像换成了正式版
  • 更改了窗口模式下的窗口尺寸
  • 手册改为编译好的 HTML 格式
  • 修正了角度运算
  • 修正了从游戏中返回标题画面时可能残留残影的问题
  • 内嵌了 MIDI 初始化
  • 修改了一部分设置画面的图形图案
  • 修正了在第 4 关 Boss 战中途返回标题画面后，其后的背景绘制有一部分会变得不对劲的问题
  • 修正了第 1 关 Boss 自爆后仍可被破坏的问题
  • 修正了旋转绘制时闪光效果存在的问题
  • 修正了一部分对象 Z 轴不自然的地方
  • 更改了一部分杂兵的配置
  • 追加了一部分处理
  • 修正了第 5 关中 Boss 自爆后部件失去判定的问题
  • 追加了一部分特效
  • 其他还改动了许多细小的地方

　

  • Ver1.00 -> Ver1.01 变更内容
  • 修正了 Continue 时名字登录出现的问题
  • 修正了通关后通关次数不计数的问题
  • 修正了关卡选择功能不生效的问题
  • 修正了满足某条件时开场画面显示坐标偏移的问题
  • 修正了演示播放中暂停仍然生效的问题
  • 修改了一部分开场图形
  • 修改了一部分结尾图形
  • 修正了第 1 关 Boss 背景卷动不自然的部分
  • 修正了第 3 关 Boss 满足条件时程序强制退出的问题
  • 改为分数显示时同时显示难度
  • 改为关卡选择时显示最高分
  • 整体追加、修改了特效
  • 对一部分难度进行了再调整
