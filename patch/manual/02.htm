２．运行方法

  • 程序的启动方法

    • 请运行 CD-ROM 或安装了程序全套文件的文件夹中的「Kamui.exe」。

    　

  • 特殊的启动方法

运行 CD-ROM 或程序所在文件夹中的「SetupKamui.exe」，会启动「启动菜单」。
选择好运行环境后请按下「开始游戏」按钮。　
采用这种启动方式，除窗口模式启动外，还可以进行多项特殊设置。
启动菜单的说明　

　

  • 关于安装（仅限 SITER SKAIN 直接销售的自费出版物版）

安装本程序时，请运行 CD-ROM 内的「Setup.exe」。安装程序启动后，请按照提示进行操作。
　※GameLand2000 版不在此说明范围内。详情请参阅附带的书册说明书。
　游戏内容本身，GameLand2000 版与 SITER SKAIN 版完全相同。

　

  • 关于卸载（仅限 SITER SKAIN 直接销售的自费出版物版）

使用 ver1.09 之后的安装程序安装的场合，请在控制面板→「添加或删除程序」中选择「神威ver1.xx」进行删除。
ver1.06 及更早版本的场合，直接删除安装文件夹即可。（本安装程序不会修改注册表。）
※GameLand2000 版不在此说明范围内。详情请参阅附带的书册说明书。
　

　

　

  • 注意

从 CD 直接启动程序的场合，无法以 CD-DA 方式播放音乐。
需要从 CD 启动程序时，请在设置画面中将音源指定为 MIDI。
想以 CD-DA 方式欣赏音乐时，请将程序全套文件安装到硬盘后再运行。
ver1.09 之后不再考虑从 CD 启动的情况。请使用 setup.exe 将程序安装到硬盘后再运行。
