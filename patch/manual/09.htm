９．补充事项

  • 游戏设置的保存

    游戏中的设置及游戏分数，保存在 Windows 文件夹内名为「siterskainSISW-991201kamui.sav」的文件中。想初始化分数时，请删除该文件。
    ※ver1.03 起有所变更。旧文件为 [siskamui.sav]。ver1.02 之前与 ver1.03 之后的文件转换会自动进行，无需在意。
    ※ver1.10 版开始，分数数据改保存在程序所在文件夹内的「savedata.sav」中。

    　

  • 安装到硬盘及卸载的方法

    本程序可以直接从 CD 运行，但安装到硬盘后能更舒适地游玩。安装方法是运行「Setup.exe」，或在硬盘上新建任意文件夹，将 CD 内的数据原样全部复制进去。
    ※ver1.09 版开始，请使用 setup.exe 安装到硬盘。仅将 CD 内的文件原样复制是无法游玩的。
    卸载时直接删除文件即完成。程序不会修改任何注册表。
    （由 MSD-JAPAN 发售的 GameLand2000 版不在此说明范围内。请按照附带手册的说明进行操作。）

    　

  • 关于从 CD 运行

    从 CD 运行程序的场合，用 CD-DA 播放音乐时声音可能中途中断。想以 CD-DA 方式欣赏游戏音乐时，请将本程序安装到硬盘后再从那里运行。
    ※ver1.09 版开始不再支持从 CD 启动。

    　

  • 关于切换全屏

    极少数环境下切换全屏时，会出现「画面全黑但只有音乐在播放」的现象。遇到这种情况，请尝试以下方法。

    １．将显卡驱动更新到最新版本。
    ２．更改显卡的硬件加速级别。
    ３．重启机器后重新运行程序。

    这些方法也可能无法改善，这是机器特有的现象，敬请谅解。

    　

  • 关于游戏中切换画面模式

      游戏中按下 F4、F5、F6 键，可以分别切换 窗口模式<->全屏、320x240 模式<->640x480 模式、画面正方形模式<->画面竖置模式等各种画面模式。但是，在游戏中途进行这些操作可能导致运行不稳定。这些设置请尽量在启动菜单中完成，不建议在游戏中途更改。
