履歴

　

  • Ver1.09 -> Ver1.10変更点
  • 全画面照準が表示されていなかった不具合を修正。
  • スコアデータの保存先をインストール先フォルダと同じ場所に変更。
　
  • Ver1.08 -> Ver1.09変更点
  • 起動時のデフォルト設定を、フレームスキップなし、解像度640ｘ480、PCMによる音楽再生に変更。
  • 各ステージタイトル、OP、ED、等の文字フォントを高解像度用に変更。
  • 設定用exeから起動するマニュアルを、html形式に変更。半透明をメッシュにするモードを削除。
  • ver1.09ベースのインストーラーに変更。

　

  • Ver1.06 -> Ver1.08変更点
  • Ogg VorbisによるBGM再生に対応。
  • 特殊描画として縦ラインスクロールを追加。
  • PCMによるBGM再生対応による必要動作スペック向上。
　
  • Ver1.04 -> Ver1.06変更点
  • 2面で一部キャラクタが消えないバグを修正。
  • 縦長画面モードを追加。
  • 各種エフェクトを追加。
  • 特殊描画エフェクトを追加。
  • ステージセレクトでゲームをプレイ中、中断するとステージセレクトに戻るように変更。
  • 起動メニューをver1.06対応版にすると共に情報を保存するように変更。
  • スクリーンセーバー及び省電力モード対策処理を追加。

　

  • Ver1.03 -> Ver1.04変更点
  • 不正終了してしまう可能性があるバグを修正

　

  • Ver1.02 -> Ver1.03変更点
  • 起動直後に不正終了する可能性があったのを修正
  • ゲーム中不正終了する可能性があったのを修正（できたと思うー）
  • 一部敵機追加　
  • 雷刀でのレーザー打消しアニメーションが表示されていなかったのを修正
  • セーブファイルのフォーマットを変更
  • 量産機使用可能モードを実装
  • 例によってその他こまかな部分を多数変更

　

  • Ver1.01 -> Ver1.02変更点
  • 起動用アプリケーションの追加及び画面モード選択方法の変更　
  • 640x480の解像度に対応
  • 3DCG系の画像を正式版に差し換え
  • ウインドウモードでのウインドウサイズを変更
  • マニュアルをコンパイル済html形式に変更
  • 角度演算を修正
  • ゲーム中からタイトル画面に戻った時にゴミが残る事がある不具合を修正
  • MIDI初期化の組みこみ
  • 設定画面グラフィックパターンを一部修正
  • 4面ボス戦途中ででタイトル画面に戻った時、それ以降背景の描画が一部怪しくなる不具合を修正
  • 1面ボスが自爆した後も破壊可能な不具合を修正
  • 回転描画時、フラッシュ効果に不具合があったのを修正
  • 一部オブジェクトのZ軸が不自然なところを修正
  • 一部の雑魚の配置を変更
  • 一部処理を追加
  • 5面中ボス、自爆したらパーツに判定が無くなる不具合を修正
  • エフェクトを一部追加
  • その他細かな部分を多数変更

　

  • Ver1.00 -> Ver1.01変更点
  • コンティニューした場合に起こるネームエントリの不具合を修正
  • クリアしてもクリア回数がカウントされない不具合を修正
  • ステージセレクト機能がはたらかない不具合を修正
  • ある条件を満たすとオープニング画面表示座標がずれる不具合を修正
  • プレイデモで一時停止が効いてしまう不具合を修正
  • オープニンググラフィックパターンを一部修正
  • エンディンググラフィックパターンを一部修正
  • 一面ボスの背景スクロールが不自然な部分を修正
  • 3面ボスで条件を満たすとプログラムが強制終了する不具合を修正
  • スコア表示時に難易度表示するように変更
  • ステージセレクトでハイスコア表示するように変更
  • 全体的にエフェクト追加、修正
  • 一部難易度再調整
